# Nexus RMM - Windows RDP Deployment Guide

## Domain: mezfashion.pro

---

## Quick Start (Run as Administrator)

```powershell
# 1. Extract deployment package to C:\NexusRMM
# 2. Run deployment script
cd C:\NexusRMM
.\deploy.ps1 -Domain mezfashion.pro -DBPassword "your_secure_password"

# 3. Configure DNS (see DNS section below)
# 4. Install PostgreSQL & Redis (see Database section)
# 5. Start service
Start-Service NexusRMM-Relay

# 6. Verify
curl -k https://relay.mezfashion.pro:8443/health
```

---

## Prerequisites (Install on RDP Server)

### 1. PostgreSQL 15+
- Download: https://www.postgresql.org/download/windows/
- Install with default settings
- Remember superuser password

### 2. Redis (Memurai for Windows)
- Download: https://www.memurai.com/get-memurai
- Or use WSL2: `wsl --install -d Ubuntu` then `sudo apt install redis-server`

### 3. Nginx (for web console on port 443)
- Download: https://nginx.org/en/download.html
- Extract to `C:\nginx`

### 4. OpenSSL (for certificates)
- Usually included with Git for Windows: `C:\Program Files\Git\usr\bin\openssl.exe`
- Or download: https://slproweb.com/products/Win32OpenSSL.html

## DNS Configuration

Add these records at your DNS provider (Cloudflare, GoDaddy, etc.):

| Type | Name | Value | TTL |
|------|------|-------|-----|
| A | relay | YOUR_RDP_PUBLIC_IP | 300 |
| A | @ | YOUR_RDP_PUBLIC_IP | 300 |
| A | www | YOUR_RDP_PUBLIC_IP | 300 |

**Test DNS:**
```powershell
nslookup relay.mezfashion.pro
nslookup mezfashion.pro
```

## Database Setup

```sql
-- Connect as postgres superuser
psql -U postgres

-- Create database and user
CREATE DATABASE nexusrmm;
CREATE USER nexusrmm WITH ENCRYPTED PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE nexusrmm TO nexusrmm;

-- Enable required extensions
\c nexusrmm
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "pgcrypto";
```

Update `C:\NexusRMM\config\config.yaml` with your database credentials.

## Certificate Generation (Auto-generated by deploy.ps1)

The deploy script generates:
- `C:\NexusRMM\certs\ca.crt` / `ca.key` - Root CA (10 years)
- `C:\NexusRMM\certs\server.crt` / `server.key` - Server cert (2+ years)
  - SANs: relay.mezfashion.pro, mezfashion.pro, localhost

**For production:** Use Let's Encrypt or your CA instead.

## Web Console Deployment

The `web/` folder contains static assets. Serve via Nginx:

### Nginx Config (`C:\nginx\conf\nginx.conf`):

```nginx
events { worker_connections 1024; }

http {
    include       mime.types;
    default_type  application/octet-stream;
    
    # Gzip compression
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;
    
    # Upstream for web console (static files)
    server {
        listen       80;
        server_name  mezfashion.pro www.mezfashion.pro;
        return 301 https://$server_name$request_uri;
    }
    
    server {
        listen       443 ssl http2;
        server_name  mezfashion.pro www.mezfashion.pro;
        
        ssl_certificate     C:/NexusRMM/certs/server.crt;
        ssl_certificate_key C:/NexusRMM/certs/server.key;
        ssl_protocols       TLSv1.2 TLSv1.3;
        ssl_ciphers         HIGH:!aNULL:!MD5;
        
        # Web console static files
        root   C:/NexusRMM/web;
        index  index.html;
        
        location / {
            try_files $uri $uri/ /index.html;
            add_header Cache-Control "public, max-age=31536000";
        }
        
        # API proxy to relay server
        location /api/ {
            proxy_pass https://localhost:8443;
            proxy_http_version 1.1;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_ssl_verify off;  # Self-signed cert
        }
        
        # WebSocket proxy
        location /ws {
            proxy_pass https://localhost:8443;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
            proxy_set_header Host $host;
            proxy_ssl_verify off;
            proxy_read_timeout 3600s;
            proxy_send_timeout 3600s;
        }
    }
}
```

Start Nginx:
```powershell
cd C:\nginx
.\nginx.exe
# Reload config: .\nginx.exe -s reload
```

## Agent Building (Run on Build Machine)

Requires: Rust 1.70+ (`curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`)

```powershell
# On build machine (can be same RDP or different)
cd C:\NexusRMM\agent
rustup target add x86_64-pc-windows-msvc
cargo build --release --target x86_64-pc-windows-msvc

# Binary: C:\NexusRMM\agent\target\x86_64-pc-windows-msvc\release\nexus-agent.exe
# Copy to C:\NexusRMM\agent\dist\ for distribution
```

## Enrollment Token Creation

After relay service is running:

```powershell
# Create enrollment token (10 uses, 24h TTL)
$token = Invoke-RestMethod -Uri "https://relay.mezfashion.pro:8443/api/v1/enroll/token" `
    -Method POST -Headers @{"Content-Type"="application/json"} `
    -Body '{"tenant_id": "default", "max_uses": 10}' -SkipCertificateCheck

Write-Host "Enrollment Token: $($token.token)"
```

## Agent Installation (On Target Machines)

```powershell
# Copy nexus-agent.exe to target machine
# Run enrollment:
.\nexus-agent.exe enroll --server relay.mezfashion.pro:8443 --token <TOKEN_FROM_ABOVE>

# Install as service:
.\nexus-agent.exe install-service --name "NexusRMM-Agent"
Start-Service "NexusRMM-Agent"
```

## Troubleshooting

### Service won't start
```powershell
# Check logs
Get-Content C:\NexusRMM\logs\relay-stderr.log -Tail 100

# Run manually to see output
C:\NexusRMM\bin\nexus-relay.exe --config C:\NexusRMM\config\config.yaml
```

### Certificate errors
```powershell
# Verify certs
openssl x509 -in C:\NexusRMM\certs\server.crt -text -noout
openssl verify -CAfile C:\NexusRMM\certs\ca.crt C:\NexusRMM\certs\server.crt
```

### Database connection failed
- Check PostgreSQL service running
- Verify config.yaml has correct host/port/user/password
- Check pg_hba.conf allows connections

### WebSocket connection fails
- Verify Nginx proxy config has `proxy_set_header Upgrade` and `Connection`
- Check relay server logs for handshake errors
- Ensure firewall allows port 8443
